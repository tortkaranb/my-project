# EcoShare

Тұрғын үй аулалары мен қала тұрғындарының сирек қолданылатын тұрмыстық техника мен құрал-саймандарды өзара уақытша жалға беру/алу ақпараттық жүйесі.

## Мақсаты
Бос жатқан заттарды қайта-қайта сатып алудың орнына, көршілердің ресурстарын біріктіру, отбасылық бюджетті үнемдеу және қала экологиясына үлес қосу.

## Пайдаланушылар
- Зат иесі (Lender)
- Арендатор (Borrower)
- Әкімші (Administrator)

## Негізгі функциялар
- Телефон нөмірі арқылы тіркелу
- Затты фотосымен жариялау
- Геолокация арқылы іздеу
- Брондау және Escrow арқылы төлем
- Хабарландырулар, рейтинг және пікірлер
